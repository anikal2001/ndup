# S1 — Notion request cost

The live workspace was not sampled. The number of requests per page and per row is unknown.

`notion/estimate.py` implements the ETA formula: mean and spread of sampled request counts, empty-body share, tokens per document, and an ETA at 3 requests/second. `ndup init` and `ndup sync --estimate` print it and store `sync_state.estimate`. With no sample, the prior is 4.5 requests/page and 1.2 requests/row (the 3–6 requests/page band in the architecture).

Fixture coverage: `tests/unit/test_analysis_cli.py` asserts the init output contains an ETA. The formula itself is `build_estimate`.
