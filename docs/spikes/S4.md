# S4 — Embedding throughput

Chunks per second for ONNX int8, CUDA fp16, and MPS were not measured. sentence-transformers and torch are not installed in the default environment, and no GPU is attached.

`ndup doctor --bench` times the configured provider. Tests pass `FakeEmbeddingProvider`, which is deterministic, L2-normalized, and opens no socket. `BAAI/bge-base-en-v1.5` is the only real model, loaded with `HF_HUB_OFFLINE=1`. CPU and CUDA register as different `embedding_model` rows so they do not share a cache.

Fixture coverage: `tests/unit/test_text_embed.py`.
